> 每个部位给出：自然微调 / 明显改善 / 大胆改造 三档说法（直接可用），以及去 AI 味红线。

> **EN:** Usage: ① translate the user's plain-language requests into precise edit actions; ② compose
> complete plans by region during plan matching. Each region gives ready-to-use wording for the three

> the edit, the higher the risk of not looking like the person.

## 0. 影棚精修档（Studio-Grade）——"摄影店精修"标准 / Studio-Grade Tier — "Pro Retouch Shop" Standard

> 当用户说"精修 / 写真级 / 摄影店水平 / 影楼水平 / 修狠一点 / 网红感"时，整套方案按本档执行。
> **精修 ≠ AI 味**：幅度可以拉满，判断红线仍然是身份、纹理和光影物理（见 anti-ai.md），
> 不是修改幅度。/ When the user says "studio retouch / editorial level / retouch shop level / go harder /
> influencer look", run the whole plan at this tier. **Heavy retouching ≠ AI look**: amplitude can be
> maxed; the red lines remain identity, texture and light physics (see anti-ai.md) — not the amount of change.

- **皮肤 / Skin**：中性灰级均匀——额头、面颊、眼周、口周**分区精细统一肤色**；痘痘、斑点、
  痘印全去；毛孔细化但保留纹理层次。双曲线（dodge & burn）：提亮面部三角区（眼下—鼻梁—下巴），
  压暗轮廓边缘和下颌阴影，让脸"立起来"。/ Zone-based evening (forehead/cheeks/eye zone/mouth zone);
  remove all blemishes; refine pores while keeping texture. Dodge & burn: lift the facial triangle,
  darken edges and jaw shadow for dimension.
- **眼睛 / Eyes**：眼神光重塑（自然双点高光）、眼白净化不发黄、睫毛根根分明、卧蚕轻提、
  眼周暗沉清干净。/ Rebuilt catchlights (natural two-point), cleaned sclera, defined lashes, subtle
  aegyo-sal lift, under-eye darkness cleared.
- **眉毛 / Brows**：按脸型精修眉形、补满空缺、边缘干净。/ Shape-appropriate brow sculpt, filled gaps,
  clean edges.
- **鼻子 / Nose**：修容式鼻梁光影（不是改结构）、鼻头精致化、鼻翼高光哑光化。/ Contour-style bridge
  shading (structure unchanged), refined tip, matte nostril highlights.
- **嘴唇 / Lips**：去死皮干裂、轮廓清晰、自然血色或方案指定唇色。/ Remove dryness, crisp outline,
  natural tint or plan-specified lip color.
- **牙齿 / Teeth**：自然白两个度以内、通透感保留、明显不齐可轻度调整。/ Whiten within two shades,
  keep translucency, mild evening of obvious misalignment.
- **脸型 / Face**：轮廓液化——下颌线、脸颊、下巴尖按方案收紧，**五官位置关系不动**。
  / Liquefy-level contouring — jawline, cheeks, chin per plan; feature positions unchanged.
- **头发 / Hair**：全头碎发清理、发际线精修（不过度整齐）、光泽统一、明显稀疏处补密。
  / Full-head flyaway cleanup, neatened (not over-neat) hairline, unified shine, fill obvious sparseness.
- **身材 / Body**（半身/全身）：肩背收薄、手臂腰线按方案处理、比例自然、**背景直线绝不弯**。
  / Slimmed shoulders/back, waist and arms per plan, natural proportions; background straight lines never bend.
- **背景 / Background**：杂物全清、路人消除、虚化程度统一。/ Full clutter and bystander removal,
  unified bokeh.
- **光影 / Light**：重塑主光质感——方向不变，但柔化正午/顶光的硬阴影、均匀提亮暗部，
  输出适度锐化。/ Rebuild light quality — direction unchanged, but soften harsh midday/top-light shadows,
  evenly lift shadows, moderate output sharpening.
- **色调 / Color**：完整调色分级，肤色与环境色分离处理。/ Full color grading with skin tones graded
  separately from the environment.
- **红线 / Red lines**：身份特征与笑容死保；皮肤纹理保留；光影方向与原图一致；不写成 flawless。
  / Identity and smile are untouchable; skin texture stays; light direction matches the original;
  never write "flawless".

## 1. 皮肤 / Skin
- **自然微调 / Subtle**：even out skin tone, remove temporary blemishes and redness, keep all natural skin texture and pores（均匀肤色，去临时性痘痘/泛红，保留全部纹理毛孔）
- **明显改善 / Noticeable**：additionally smooth visible pores slightly and reduce oily shine, while keeping realistic texture（额外轻度收毛孔、压油光，仍有真实纹理）
- **大胆改造 / Bold**：significantly brighten and refine skin to a polished look — 必须同时写 keep realistic skin texture, no plastic look / must also write "keep realistic skin texture, no plastic look"
- **红线 / Red line**：永远不写 "perfect skin / flawless skin" 这类词；痣、雀斑属个人特征，默认保留，除非用户点名去除。/ Never write "perfect/flawless skin"; moles and freckles are personal traits — keep by default unless the user asks to remove them.

## 2. 脸型与轮廓 / Face shape & contour
- **自然微调 / Subtle**：subtly define jawline, reduce minor double-chin shadow（轻微强化下颌线、减淡双下巴阴影）
- **明显改善 / Noticeable**：gently slim face sides and sharpen jaw contour, keep face shape recognizably the same（脸颊轻微收窄、下颌轮廓更清晰，脸型仍可辨认）
- **大胆改造 / Bold**：noticeably reshape to V-line — 风险极高，必须先给用户看"脸型变化大"的预警，并确认保留五官位置关系 / high risk: warn the user about the big face-shape change first and confirm feature positions are preserved
- **红线 / Red line**：不动头骨比例，不改变耳朵位置；左右脸不对称是真实的，不要拉对称。/ Never alter skull proportions or ear positions; facial asymmetry is real — do not symmetrize.

## 3. 眼睛与眼周 / Eyes & under-eye
- **自然微调 / Subtle**：reduce under-eye puffiness and dark circles slightly, keep natural eye shape, add subtle catchlights（轻微减淡眼袋黑眼圈，眼型不动，补自然眼神光）
- **明显改善 / Noticeable**：make eyes look more awake and defined, slight lid enhancement without changing single/double eyelid（更有神、眼部轮廓更清晰，不动单双眼皮属性）
- **大胆改造 / Bold**：larger-looking eyes — 必须写 keep natural proportions, avoid doll-like eyes / must write "keep natural proportions, avoid doll-like eyes"
- **红线 / Red line**：虹膜颜色、眼睛大小比例是身份特征；眼线睫毛加浓属妆容范畴，要先经用户确认。/ Iris color and eye size are identity traits; heavier liner/lashes are makeup — get user confirmation first.

## 4. 鼻子 / Nose
- **自然微调 / Subtle**：reduce shine on the T-zone, keep nose shape unchanged（压 T 区油光，鼻型不动）
- **明显改善 / Noticeable**：slightly refine nose bridge and tip definition through contouring-like shading（用光影让鼻梁更挺、鼻头更精致，结构不变）
- **大胆改造 / Bold**：reshape nose — 通常建议改用"妆容式修容"达到视觉缩窄，避免直接改结构 / prefer "makeup-style contouring" for visual narrowing instead of restructuring
- **红线 / Red line**：鼻梁高光、鼻翼宽度一改就容易不像本人，"明显改善"以上必须用户确认。/ Bridge highlight and nostril width easily break likeness — "noticeable" and above requires explicit user confirmation.

## 5. 嘴唇与牙齿 / Lips & teeth
- **自然微调 / Subtle**：restore natural lip color and moisture, remove dryness cracks（恢复自然唇色水润，去干裂）
- **明显改善 / Noticeable**：slightly fuller and more defined lips with a natural tint（轻度丰唇 + 自然血色感）
- **大胆改造 / Bold**：change lip shape/color to <指定色> — 明确说这是妆容效果 / state clearly this is a makeup effect
- **牙齿红线 / Teeth red line**：whiten teeth moderately, keep natural translucency and slight imperfection（适度美白，保留自然通透和轻微不齐，不要写成 perfect white teeth）。/ "whiten teeth moderately, keep natural translucency and slight imperfection" — never "perfect white teeth".

## 6. 眉毛 / Brows
- **自然微调 / Subtle**：fill sparse gaps following original brow shape, clean stray hairs（按原眉形补空缺、修杂毛）
- **明显改善 / Noticeable**：reshape brows to <平眉/弯眉/挑眉> while suiting face shape / reshape to <straight/arched/lifted> to suit the face
- **红线 / Red line**：眉形改变气质很大，"明显改善"以上先给用户文字确认。/ Brow shape changes vibe a lot — get written confirmation at "noticeable" and above.

## 7. 头发 / Hair
- **自然微调 / Subtle**：tame frizz and flyaways, add natural shine（抚平毛躁碎发，加自然光泽）
- **明显改善 / Noticeable**：add volume and fullness, neaten hairline, keep original hairstyle and color（增发量蓬松感、发际线修整，发型发色不动）
- **大胆改造 / Bold**：change hairstyle/color to <指定> — 需确认是否保留原发色以供辨认 / confirm whether to keep the original color for recognizability
- **红线 / Red line**：发际线不能修成完美弧线；发丝必须根根可见；额前碎发是灵气，别全抹掉。/ No perfect-arc hairlines; individual strands must stay visible; don't erase all baby hairs.

## 8. 身材（仅限半身/全身照）/ Body (half/full body only)
- **自然微调 / Subtle**：improve posture slightly, smooth clothing wrinkles（微调体态、抚平衣皱）
- **明显改善 / Noticeable**：subtly slim waist/arms and elongate legs, keep natural body proportions（收腰/手臂/拉腿但比例自然）
- **大胆改造 / Bold**：significant body reshaping — 必须先让用户确认强度，并预警背景线条弯曲风险 / confirm intensity first and warn about bending background lines
- **红线 / Red line**：透视背景里的直线（门框、栏杆）不能弯；手指数量结构不能错。/ Straight lines in perspective (doors, railings) must not bend; finger counts and structures must be correct.

## 9. 背景 / Background
- **杂物清除 / Clutter removal**：remove distracting background objects, seamlessly fill the area（去除干扰物并无缝填补）
- **虚化增强 / Bokeh enhancement**：natural depth-of-field blur consistent with lens optics, clean edges around hair（符合镜头物理的自然虚化，发丝边缘干净）
- **换背景 / Swap**：replace with <场景> — 必须写 match original lighting direction and color temperature on subject, realistic hair-edge blending（新背景光源方向、色温必须与原图人物受光匹配）
- **红线 / Red line**：换背景后人物受光必须与新场景一致，见 anti-ai.md §4。/ After a swap, subject lighting must match the new scene — see anti-ai.md §4.

## 10. 光线与影调 / Light & tone
- **去 AI 味红线 / Anti-AI red line**：光影方向永远以原图为准，提示词写 match the original lighting direction。/ Light direction always follows the original — write "match the original lighting direction".
- **提亮暗部 / Lift shadows**：lift shadows on face while keeping original light mood（提面部暗部，保持原有光感）
- **柔化硬光 / Soften hard light**：soften harsh shadows from direct flash/sun（柔化直射闪光/阳光的硬阴影）
- **整体换氛围 / Mood swap**：仅在用户选了风格模板时使用对应影调词。/ Full mood changes only with a user-picked style template.

## 11. 方案匹配方法 / Plan-matching method

1. 从照片提取三个约束：① 场景与光线（室内/户外/夜景；顺光/逆光）② 人物气质
   （清冷/亲和/浓颜/淡颜；年龄感）③ 照片用途线索（穿搭→全身；自拍→面部）。
   / Extract three constraints: ① scene & light (indoor/outdoor/night; front/backlit) ② vibe
   (cool/warm/rich/soft features; age feel) ③ purpose cues (outfit → full body; selfie → face).
2. 从 style-library.md"方案匹配速查"表取 3 个风格方向，交叉本文件
   各部位"自然微调/明显改善"档，组成三套完整方案。
   / Take 3 style directions from the quick table in style-library.md and cross them with the
   subtle/noticeable levels of each region in this file to compose three complete plans.
3. 风格已定（用户第 3 问选了方向）：三套方案在同一方向下做强度差异——
   自然档（全部"自然微调"）/ 出片档（关键部位"明显改善"）/ 大胆档（主要部位"大胆改造" +
   风险提醒）。风格未定：三套跨风格，差异明显（如清透自然 vs 港风浓颜 vs 韩系画报）。
   / Style decided: three intensity tiers in that direction — subtle tier (all "subtle") / polished tier
   (key regions "noticeable") / bold tier (main regions "bold" + risk warnings). Undecided: three
   clearly different cross-style plans.
4. 每套方案按 SKILL.md 第 2 步的详细格式撰写（修哪里/怎么修/整体风格/改后效果/
   适合场景/风险提醒），【改后效果】2–3 句具体描述，禁止简略。
   / Write each plan in the detailed format from SKILL.md Step 2 (where / how / style / result /
   best-for / risks); the 【Result】 section needs 2–3 concrete sentences — no brevity.
