# 引导式提问剧本（三轮提问 → 第 4 问滤镜 → 第 5 问补充 → 详细方案）/ Guided Interview Script (3 questions → Q4 filter → Q5 supplements → detailed plans)

> 目的：用尽可能少的轮次，拿到"修哪里 / 怎么修 / 整体风格 / 滤镜 / 补充信息"五要素，
> 然后给用户至少 3 套**详细**方案选择。
> 纪律：**一次只问一个问题**；用户回答后先复述确认再进下一问；
> 用户说"随便/你看着办"时，给 2–3 个具体选项让其挑，绝不替用户做决定。
>
> **EN:** Goal: capture the five elements — where / how / style / filter / supplements — in as few turns
> as possible, then present at least 3 **detailed** plans.
> Discipline: **one question at a time**; recap and confirm each answer before the next question;
> if the user says "whatever / you decide", offer 2–3 concrete options — never decide for them.

## 开场（第 0 步分析的输出）/ Opening (output of the Step-0 analysis)

提问开始前，必须先输出对照片的分析（格式见 SKILL.md 第 0 步）：光线、皮肤、五官、
构图、背景氛围逐项指出问题/优点，并给 2–3 个推荐方向。然后接第 1 问。

> **EN:** Before any question, deliver the photo analysis (format in SKILL.md Step 0): light, skin,
> features, composition, background/mood — issues and strengths item by item — plus 2–3 recommended
> directions. Then proceed to Q1.

## 第 1 问：修哪里（What）/ Q1: What to edit

> 这次最想调整哪些地方？结合上面的分析，可以选这些，也可以说别的：
> - 皮肤（瑕疵/肤色不均/油光/暗沉）/ skin (blemishes / uneven tone / oil shine / dullness)
> - 脸型轮廓（下颌线/脸颊/双下巴）/ face contour (jawline / cheeks / double chin)
> - 五官（眼睛/鼻子/嘴唇/眉毛）/ features (eyes / nose / lips / brows)
> - 牙齿（美白/整齐度）/ teeth (whitening / evenness)
> - 头发（发际线/蓬松度/毛躁/发色）/ hair (hairline / volume / frizz / color)
> - 身材（仅限半身/全身照：肩线/腰线/手臂）/ body (half/full body only: shoulders / waist / arms)
> - 背景（虚化/杂物清除/换背景）/ background (bokeh / clutter removal / swap)
> - 光线（太暗/太硬/锐化重/想换氛围光）/ lighting (too dark / too harsh / over-sharpened / new mood)
> - 构图（人物占比/裁剪/画幅）/ composition (subject size / crop / aspect ratio)

用户说完后复述："好，要动的是 A、B、C，对吗？" 确认后进第 2 问。
如果用户说"全部都想更好"，引导排序："如果只能优先三处，你最先想改善哪三处？"

> **EN:** After the user answers, recap: "So we will adjust A, B, C — correct?" Confirm, then Q2.
> If the user says "make everything better", ask them to prioritize: "If you could only pick three, which first?"

## 第 2 问：怎么修（How + 程度 + 保留项）/ Q2: How (degree + keep-list)

针对第 1 问选中的每一项，确认两点 / For each item selected in Q1, confirm two things:

1. **程度 / Degree**：自然微调（熟人看不出修过）/ 明显改善（看得出变好看了但说不出哪变了）/
   大胆改造（突破原图限制）。/ subtle (friends can't tell) / noticeable (clearly better, unplaceable) /
   bold (break the limits of the original).
   默认推荐"自然微调"或"明显改善"，并说明：
   > 建议自然或明显改善这个程度，修得太狠容易不像你、也有 AI 感，你倾向哪种？
   > **EN:** "Subtle or noticeable is recommended — heavy edits risk not looking like you and add AI feel. Which do you prefer?"

2. **保留项（必问）/ Keep-list (mandatory)**："脸上有没有什么是绝对不能动的？比如痣、单眼皮、
   笑容的样子、梨涡这类你的个人标志。" / "Is there anything on your face that must never change? Moles,
   monolid, the way you smile, dimples — your personal signatures." 用户没说也要问，并把答案记入方案。
   Ask even if unprompted and record the answer in the plans.

复述确认后进第 3 问。/ Recap, confirm, proceed to Q3.

## 第 3 问：整体风格（Style / 用途）/ Q3: Overall style (style / purpose)

> 修完之后想要什么样的整体感觉？可以从用途倒推：
> - 日常自然（像没修过，只是状态好）/ everyday natural (looks untouched, just well-rested)
> - 社交出片（精致、有氛围感，适合发小红书/朋友圈）/ social-ready (polished, moody, for RED/Moments)
> - 形象照（求职/领英/工牌，干净专业）/ professional headshot (job/LinkedIn/badge, clean)
> - 写真感（胶片/港风/日系等明确风格）/ photoshoot look (film / HK retro / Japanese etc.)
> - 没想法，你帮我配 / no idea — you match for me

用户明确给出风格 → 记录，进第 4 问。用户说"不知道/你看着办" → 记录"风格未定"，
**不要追问**，进第 4 问。

> **EN:** If the user names a style, record it and go to Q4. If they say "I don't know / you decide",
> record "style undecided", do NOT probe, go to Q4.

## 第 4 问：选滤镜（第 4 问，在补充环节之前）/ Q4: Pick a filter (before supplements)

从 style-library.md 中选 5–6 个最贴合已确认方向的模板名给用户：

> 想顺手套一个现成滤镜吗？目前有：
> ①〈模板名〉②〈模板名〉③〈模板名〉④〈模板名〉⑤〈模板名〉⑥不套，保持自然。
> 选好后我最后确认几个补充问题就出方案。

> **EN:** "Want to throw on a ready-made filter? We have: ①... ②... ③... ④... ⑤... ⑥ none, stay natural.
> Pick one and I'll confirm a few last supplements before presenting plans."

用户选定或明确跳过 → 进第 5 问。/ Once picked or skipped, go to Q5.

## 第 5 问：补充环节（最后一问）/ Q5: Supplements (final question)

主动追问，覆盖以下维度中用户还没提过的（挑 3–5 个最相关的问，别机械全问）：

- 有没有喜欢的参照对象（明星/博主/某张图的感觉）？/ any reference (celebrity/creator/a certain look)?
- 有没有绝对不能出现的元素（比如不要浓妆、不要换发型）？/ any hard no's (no heavy makeup, no hairstyle change)?
- 要不要化妆感（裸妆/淡妆/浓妆）？/ makeup level (none / light / heavy)?
- 用途和发布平台？（决定比例和风格强度）/ purpose and platform? (drives ratio and style intensity)
- 尺寸比例要求？（头像 1:1 / 竖版 3:4 / 保持原图）/ aspect ratio? (1:1 avatar / 3:4 vertical / keep original)
- 想要几张备选？/ how many variants?

收尾确认："以上都没有遗漏了吗？还有要补充的随时说——确认后我出方案给你挑。"
**用户确认后提问环节关闭，不再追加问题。**

> **EN:** Close with: "Anything missing? Add anything anytime — once confirmed, I'll present the plans."
> **After the user confirms, the Q&A phase is closed — no more questions.**

## 方案阶段（五问全部结束后必做）/ Plan Phase (mandatory after all five questions)

出至少 3 套方案，**每套必须详细**，用 SKILL.md 第 2 步的格式：
修哪里（逐项）/ 怎么修（动作+程度）/ 整体风格 / 改后效果（用户能想象出成片）/
适合场景 / 风险提醒。

- 风格已定：出同一方向下的自然档 / 出片档 / 大胆档三套强度差异方案
  / Style decided: three intensity tiers within that direction — subtle / polished / bold.
- 风格未定：出跨风格的三套"不同的自己"，明确可混搭
  / Undecided: three cross-style "different selves"; mixing explicitly allowed.
- 每套方案的【改后效果】至少 2–3 句具体描述（肤色、光线、色彩、质感、像什么场景
  拍出来的），**禁止"变得更美"这类空话**
  / Each plan's 【Result】 needs 2–3 concrete sentences (skin, light, color, texture, what scenario it
  resembles). **"Become prettier" style filler is forbidden.**

结尾话术："你选一套，或者说'A 的构图 + B 的色调'混搭也行——选定我就开修。"

> **EN:** Closing line: "Pick one — or mix, like 'Plan A's composition + Plan B's grading'. Once chosen, I start editing."

## 提问中的常见情况处理 / Handling Common Situations

| 用户行为 / User behavior | 处理方式 / Handling |
|---|---|
| 一口气说了所有需求 / dumps all requirements at once | 跳过已答问题，复述全部需求一次，补齐缺失问题后关闭提问 / skip answered questions, recap once, fill gaps, close Q&A |
| 中途给新的参考图/新照片 / sends new reference/photo mid-way | 重新做第 0 步分析，已确认的需求仍然有效，问差异部分 / redo Step-0 analysis; confirmed needs stay valid; ask only about differences |
| 要求"修得像某某明星" / "make me look like <celebrity>" | 只提取风格特征（妆感、光线、色调、构图），明确告知不动五官结构，避免身份替换 / extract style traits only (makeup, light, color, composition); state clearly that feature structure won't change; avoid identity swap |
| 回复极短（"好看就行"）/ ultra-short replies ("just make it pretty") | 给 2–3 个具体选项让其挑；仍不选则按"明显改善 + 保持个人特征"默认推进，并在第 5 问告知默认假设请求确认 / offer 2–3 concrete options; if still no choice, default to "noticeable + preserve personal traits" and state the assumption at Q5 for confirmation |
